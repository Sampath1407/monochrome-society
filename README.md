# 🖤 Monochrome Society

### A monochrome art-sharing platform built for artists and art enthusiasts.

Monochrome Society is a full-stack web application designed around the idea of sharing and discovering black-and-white artwork.

The platform allows users to explore artworks, view individual artwork details, share stories associated with artworks, and submit their own artwork.

## 🌐 Live Demo

🔗 **[Visit Monochrome Society](https://monochrome-society.onrender.com)**

---

## ✨ Features

- 🎨 Explore monochrome artworks
- 🖼️ Individual artwork detail pages
- 📝 Submit artwork through a web form
- 💬 Share stories associated with artworks
- 👤 Artist and profile sections
- 📖 Artist notes and artwork descriptions
- 🔄 Dynamic content rendering using Flask
- 📡 REST API endpoints for artwork stories
- 🗄️ SQLite database integration
- 📱 Responsive web interface
- 🖤 Minimal monochrome visual design
